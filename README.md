Es un sistema que sirve para consultar en detalla las facturas pendientes por cancelar un propietario 
en un edificio donde tengo un Sistema de Control de Condominio hecho en Cobol, genero un archivo TXT
con renglones de cada factura que debe, luego la convierto en .json, hay un script de Java que procesa
ese archivo complementandose con style.css index.html , el propietario accesa desde su telefono
una URL y consulta su cuenta.
